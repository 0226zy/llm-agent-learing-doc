## 推荐学习路径

1. **补基础**：先读概率论与神经网络资料，建立概率、梯度、序列模型和注意力的基本直觉。
2. **读懂 Transformer**：对照原论文和中英批注，手算一次 Q、K、V 与缩放点积注意力。
3. **完成小模型实战**：跟随 nanoGPT 或《从零跑通》，实现分词、训练、反向传播和推理。
4. **深入训练与推理系统**：学习分布式训练、Prefill／Decode、KV Cache、vLLM 和集群成本。
5. **进入 Agent 工程**：理解 Agent Loop、工具、上下文、持久状态、验证护栏与评测。
6. **串联产品与架构**：通过原型构建平台文档，把模型能力、Runtime、沙箱、控制层和 Web 层串成完整系统。

时间有限时，可采用速读路线：**《大模型关键 30 篇》→ Transformer 中文批注 →《大模型训练与推理工程详解》→《Agent Harness 技术学习卡片集》→《agent-runtime 架构》**。

## 使用说明

- PDF 和 HTML 可直接阅读；HTML 文档建议使用浏览器打开。
- Markdown 版本适合继续批注、拆分卡片或维护个人学习笔记。

- 资料中的版本信息、实验数据与外部结论以各文档标注的来源和时间为准；用于生产决策前应复核最新官方文档。
